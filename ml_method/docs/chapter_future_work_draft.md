# Future work

DRAFT for the thesis. Prose style follows the thesis convention of no semicolons, no
non-mathematical parentheses, and no em-dashes. The directions are ordered by how directly they
follow from the results and the diagnostic.

## Rebuild the backbone

The diagnostic identifies the ASTRAL backbone as the binding limitation. On the validation split
the backbone contributes 0.071 of the model's 0.113 mu-distance, while the model's own event
prediction contributes only 0.014, so the species tree, not the events, is what caps
in-distribution quality. The method stamps events onto a fixed backbone and never rearranges it, so
every backbone error is inherited. The natural next step is to rebuild the backbone before or during
reconstruction, for example by phasing the polyploid subgenomes so that ASTRAL sees single-copy
lineages and places them more coherently. This is the only lever the diagnostic leaves that can
lower the mu-distance materially on in-distribution networks.

## Train on the target distributions

The model is trained on clean discordance, incomplete lineage sorting and duplication and loss at a
single effective population size, and is evaluated as a generalization test on fractionation and on
two further effective population sizes. Its losses on those regimes are therefore ambiguous, since
they mix a limitation of the approach with the fact that it never trained on the regime. The
benchmark shows the gap to Polyphest is smallest exactly in the corrupted regimes, high duplication
and loss and moderate fractionation, where the method already leads on reticulation recovery. So
training on those distributions, in particular on fractionated data, is the direction most likely
to close the mu-distance gap where it is closable. It also removes a methodological weakness. The
ploidy-free decode threshold is at present calibrated on clean validation data, which is the wrong
distribution for a decode whose purpose is corrupted data, and a fractionated training set would
provide a held-out fractionated split on which to calibrate it honestly. Fractionated training data
can be generated by the same post-hoc pruning that produced the fractionation benchmark, applied to
the training gene trees, so it does not require new simulation.

## Exact-ploidy decode by constrained selection

The ploidy-informed decode fills each species up to its inferred copy number greedily, taking events
in order of detection confidence and stopping at the bound. This is a greedy approximation of a
cleaner objective. One could instead search for the set of predicted events that meets every
species copy number exactly and has the highest total detection confidence among all such sets. This
is a constrained optimization over the model's own predictions, so it invents nothing, and it
returns the most confident event set consistent with the inferred ploidy rather than a
confidence-ordered prefix of it. The greedy fill and the exact objective agree when the confident
events do not compete for a shared copy-number budget, so the gain is expected on networks with
overlapping events, at the cost of a search. This is a bounded and well-defined improvement to the
decode that is worth measuring.

## Iterative MUL-tree decoding

The build residual in the diagnostic is concentrated on networks with nested or overlapping
reticulations, where one event is placed inside a region another event has already reshaped, and the
one-shot decode cannot always recover the second event's structure. Iterative GRAMPA, which searches
for reticulations one at a time, is also the strongest method at the most severe fractionation. Both
point to an iterative decode. The model would predict one event, apply it to produce a partial
reconstruction, re-extract features on that partial structure, and predict the next event, repeating
until no confident event remains. This requires a model trained to read a partially reconstructed
MUL-tree rather than only the original gene trees, and it targets exactly the nested-event case that
the current one-shot decode handles worst.

## Learned gene-tree encoding

The method reads the gene trees through hand-crafted per-edge features, namely copy distributions,
branch-length asymmetry, and clustering structure. An earlier version that learned an encoding of
the gene trees directly, rather than hand-crafting these features, did not improve on them. That
does not close the direction, because the earlier encoder was a specific and limited architecture.
A stronger encoder, for example one that pools over gene trees with attention so the model can weight
informative genes, could capture statistics the hand-crafted features miss, and it is the natural way
to lift the ceiling on event and partner prediction that hand-crafted features have reached. This is
the higher-risk direction, since the first attempt failed, but also the one with the most headroom if
it works.
